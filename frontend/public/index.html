Questions

Open an issue on GitHub

Is there a price for plainml?

No. It is free and open source under the MIT licence, and the website costs nothing to use.

Where does my spreadsheet go?

Nowhere. In the browser version Python runs inside the page; with plainml web it stays on your machine.

Which spreadsheet files can I upload?

CSV, Excel, Parquet, JSON and TSV, up to 200 MB in the browser. The command line also reads URLs and databases.

Do I need to know machine learning?

No. Pick a column and a task; plainml chooses the methods and explains the result.

When is other machine learning software better?

For the last fraction of accuracy on a very large dataset. AutoGluon or a cloud platform will do better there.

Can I use the model in my own apps?

Yes. Download it, serve it as an API with plainml serve, or build a Docker image for it.

Your spreadsheet never leaves your computer

On the website, Python, scikit-learn, LightGBM and XGBoost run inside the web page, so nothing is uploaded. Installed with pip, plainml web runs on your own machine.
